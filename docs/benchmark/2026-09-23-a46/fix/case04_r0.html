ONBOARDING

開発環境セットアップ手順

はじめての方はこの 5 ステップを上から順に進めてください（所要 30〜40 分）

  1. 1

    リポジトリを clone する

    社内 GitHub の SSH 鍵を登録したうえで git clone します。

    作業ディレクトリはホーム直下の ~/src/ に揃えておくと、後の手順のパスがそのまま使えます。

  2. 2

    ツールチェーンを導入する

    コンパイラとビルドツールを、リポジトリ同梱のバージョン指定に合わせて入れます。

    バージョンがずれると後続のビルドが落ちるので、--version で必ず確認してください。

  3. 3

    依存ライブラリを取得する

    初回のみネットワーク経由で外部ライブラリを取りに行きます。回線によっては 10 分ほどかかります。

    社内プロキシ環境の場合は、先に環境変数の設定が必要です。

  4. 4

    ビルドする

    設定（configure）とビルドの 2 段階です。警告はすべてエラー扱いになっています。

    失敗したら、まずステップ 2 のバージョンを疑ってください。

  5. 5

    テストを実行する

    全テストが緑になれば環境構築は完了です。お疲れさまでした 🎉

    赤が出た場合は、ログを添えて #dev-help チャンネルに投げてください。

困ったときは：社内 wiki の「開発環境 FAQ」→ それでも解決しなければ #dev-help へ。メンターが必ず拾います。
