開発環境セットアップ手順

新しく参加した人が最初に行う 5 つの作業です。上から順に進めてください。

1
リポジトリを clone する
社内 GitHub の main リポジトリを手元に複製します。SSH 鍵の登録が先に必要です。
2
ツールチェーンを導入する
指定のコンパイラとビルドツールを入れます。版は README に固定してあります。
3
依存ライブラリを取得する
初回だけ時間がかかります。取得が終わるまでネットワークを切らないでください。
4
ビルドする
まず Debug 構成で通してください。警告はエラー扱いなので、出たらその場で直します。
5
テストを実行する
全件が緑になれば準備完了です。落ちたら環境の問題なので、チームに声をかけてください。
