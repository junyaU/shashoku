Incident response flow

Detect
Alerts and user reports open an incident channel.
→
Triage
Set severity and name an incident commander.
→
Mitigate
Stop the bleeding: roll back or disable the feature.
→
Communicate
Post status updates to customers every 30 minutes.
→
Postmortem
Write it up within five business days, blameless.
↑
If rollback fails twice, page the on-call lead.
