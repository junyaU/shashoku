# NOTES

各ケースの想定サイズ・主な技法・注記。

## case01 比較表
- 幅 900（body の余白込みで 940）、高さは内容依存（おおよそ 640 前後）
- table + thead の色付き見出し行、`tbody tr:nth-child(even)` で縞模様、角丸カード＋影、Google Fonts（Noto Sans JP）
- 項目列は固定幅 150px。本文はダミーの日本語（各セル 20〜40 字）

## case02 処理フロー図
- 幅 1000（余白込み 1040）、高さは内容依存（おおよそ 400 前後）
- flex で 5 段を横並び、矢印は細い div ＋ `::after` の三角（border トリック）、絵文字アイコン、注記は破線枠
- ワーカー段だけ縦方向の列にして、下に 2px の縦線で注記をぶら下げている

## case03 用語カード
- 幅 720（余白込み 760）、高さは内容依存（おおよそ 430 前後）
- 上端のグラデーション帯は `::before`、見出しと読みは flex の baseline 揃え、明朝体（Noto Serif JP）と ゴシックの混植、関連語は pill 型タグ
- 読み（べきとうせい）はルビではなく見出し横の小さな文字として配置

## case04 手順カード
- 幅 800（余白込み 840）、高さは内容依存（おおよそ 860 前後）
- ol/li を flex に、番号バッジは円＋グラデーション、バッジ同士をつなぐ縦線は `li::before` の絶対配置、コマンド名は `<code>`
- 具体的なコマンド文字列は環境によって変わるため書かず、説明のみにしている

## case05 読書メモ（SNS）
- 1080 × 1080 固定
- 明朝体、`::before` / `::after` で鉤括弧を大きく配置、内側の細罫は `inset` の枠、背景は radial + linear グラデーション
- 書名・著者は架空。右下に右寄せで配置

## case06 OG 画像
- 1200 × 630 固定
- 濃色グラデーション背景＋薄いグリッド（`repeating` ではなく 2 枚の linear-gradient）、タイトル後半は `background-clip: text` のグラデーション文字、タグは pill
- **avatar.png は同じディレクトリに利用者が置く前提**（`<img src="avatar.png">`）。無い場合は丸い枠だけが残る

## case07 イベント告知
- 1080 × 1080 固定
- flex の縦積み、登壇者は左に色帯を持つカード、ふりがなは `<ruby><rt>`、「参加無料」はグラデーションの pill ＋絵文字、右上の光は radial-gradient の円
- 登壇者名の列は 300px 固定。ふりがなが長い場合はここを広げる

## case08 週次レポート
- 幅 800（余白込み 840）、高さは内容に合わせて（おおよそ 480 前後）
- 指標は `grid-template-columns: repeat(3, 1fr)` ＋ 1px の gap を罫線代わりに、前週比は増=緑/減=赤/変化なし=グレーの pill
- ±0 は「増えても減ってもいない」のでグレーにしている（指定外の判断）

## case09 ニュース要約カード
- 幅 800（余白込み 840）、高さは内容依存（おおよそ 400 前後）
- 白背景＋1px 枠、見出し下に 2px のアクセント罫、箇条書きの点は `li::before` を 45 度回転させた四角、タグは角丸の小さな箱
- 記事内容・出典はすべて架空

## case10 短歌（縦書き）
- 800 × 1200 固定
- `writing-mode: vertical-rl`、和紙風の背景は radial + linear グラデーションの重ね、朱印は正方形の枠＋`::before` の文字
- 歌は 1 つの段落で、高さ 880px に収まらない分が自然に折り返って 2 行（2 列）になる想定。フォントによって折り返し位置がずれる場合は `height` か `font-size` を微調整する
