開発環境セットアップ手順
新しく参加した人が最初に行う 5 つの手順です。上から順に実行してください。
1
リポジトリを clone する
社内 GitHub から main を取得します。SSH 鍵の登録が済んでいない場合は先に登録してください。
2
ツールチェーンを導入する
CMake 3.22 以上と Ninja、clang-18 を入れます。バージョンは docs の表に合わせてください。
3
依存ライブラリを取得する
configure を一度走らせると、固定した版の依存が自動で取得されます。初回は数分かかります。
4
ビルドする
dev プリセットでビルドします。警告はエラー扱いなので、途中で止まったらその行を直します。
5
テストを実行する
全テストが緑になれば準備完了です。落ちたテストがあれば、まず環境の項目を確認してください。
