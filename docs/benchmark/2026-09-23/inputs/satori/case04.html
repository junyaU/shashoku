開発環境セットアップ手順
新しく入った人が最初にやること（上から順に）
1
リポジトリを clone する
GitHub の Organization に招待されていることを確認してから、SSH で clone してください。
2
ツールチェーンを入れる
CMake 3.22 以上、Ninja、clang-18 が必要です。版がずれると後の手順で必ず詰まります。
3
依存ライブラリを取得する
初回の configure でネットワークから取得します。社内プロキシ配下では環境変数の設定が要ります。
4
ビルドする
まず Debug 構成で通してください。8 並列でおよそ 3 分、二回目以降は 30 秒ほどです。
5
テストを実行する
全部通れば環境は完成です。落ちたら Slack の #dev-setup に落ちた名前を貼ってください。
