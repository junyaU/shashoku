開発環境セットアップ手順

新しく入った人が最初にやること。上から順に進めてください。

1

リポジトリの clone

社内 GitHub から作業用リポジトリを取得します。SSH 鍵の登録を先に済ませてください。

2

ツールチェーンの導入

CMake 3.22 以上、Ninja、clang-18 を入れます。版が古いと configure の途中で止まります。

3

依存ライブラリの取得

初回の configure でまとめて取得されます。回線次第で 10 分ほどかかるので待ってください。

4

ビルド

dev プリセットでビルドします。警告はエラー扱いなので、出たらその場で直してください。

5

テストの実行

全テストを走らせ、すべて通れば完了です。落ちたら結果を添えて担当者に相談してください。
