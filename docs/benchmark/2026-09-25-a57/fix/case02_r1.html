注文受付から確定までの非同期処理フロー

設計レビュー資料 ／ 2026-09-23

👤

ユーザー

ブラウザから注文フォームを送信する。受付 ID をその場で受け取る。

🖥️

API サーバー

入力値を検証し、受付 ID を採番。ジョブを積んで 202 をすぐ返す。

📥

キュー

ジョブを順番に保持する。ワーカーが落ちても取りこぼさない。

⚙️

ワーカー

在庫引き当てと決済を実行し、結果を書き戻して通知メールを送る。

再試行ポリシー
失敗時は 3 回まで再試行し、それでも失敗したら dead letter に送る
🗄️

DB

注文の確定状態を保存する。受付 ID で冪等に書き込む。

→ は処理の流れ ／ 破線の枠は運用上の取り決めを示す
