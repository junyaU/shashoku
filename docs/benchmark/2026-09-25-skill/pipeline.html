HTML 断片
タグとスタイルの部分集合
→
① html
DOM

→
② style
スタイル付きツリー
カスケード。対応外の宣言は集めて続行
→
③ layout
ボックスツリー
行分割・flex・ルビ・縦書き
→
④⑤ text · paint · raster
描画リストと Bitmap
シェーピングと塗り
→
⑥ png
PNG
同じ入力から同じバイト列
