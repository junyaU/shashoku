## 4. hint の評価（fix）

- **効いた**: `box-sizing`（8 件。引き忘れは `content-overflow` 警告が px つきで拾った）、`grid` → flex + `flex: 1 1 0`、`min-height`（条件つきの言い回しがそのまま当たった）、`inline-block` → flex の親 + `flex: none`（`inline-flex` にも流用）、ベンダー接頭辞、**gradient の hint の `background-clip: text` の注意**（case06 で見出しが消えるのを防いだ）、`position` → flex
- **誤解・不足**: `writing-mode` の hint が `ARCHITECTURE.md A1` を指す（HTML を書く側は読めない。ガイド §4.10 を指すべき）／`image-not-found` に hint が無く、渡した画像名を教えない／`transform` に hint が無い
- **辺ごとの border の hint の 2 択に無い第 3 の用途**: アクセント帯（`border-left: 4px` の識別色。case02 / 03 / 07 の 3 件）。「枠の一辺」として削ると用途を満たせない。「箱を flex 行にして先頭に 4px の div」の定石をガイドと hint に足せば代替できる

## 5. box-sizing / 辺ごとの border / overflow: hidden（関門の判定材料）

| 項目 | 今回の数字 | 読み |
|---|---|---|
| `box-sizing: border-box` | 10/10 に `* { … }`。引き算 26 か所。引き忘れは警告で拾えるが、幅を書いていない flex 項目には手がかりが無い。外形幅の不ぞろい（case02）も同根 | hint で 1 往復で直るが、毎回・全件・26 か所。対応すれば `*` セレクタ込みでそのまま通る |
| 辺ごとの `border` | 区切り線 12 + 表の縦罫 18 か所 → 1px の div で用途を満たせた。アクセント帯 3 件は満たせず | 罫は代替で足りる。帯は定石を 1 つ足せば代替できる。実装の優先度は box-sizing より下 |
| `overflow: hidden` | 7/10 が書き、落として角が崩れたのは 2 件 | 「角丸カード + 端まで届く色の子」のときだけ。ガイド §3-(5) の回避（背景は外枠だけ）で足りる場合が多い |

## 6. ガイドの不足（guided が自力で埋めた穴）

日本語: §4.7 の spacer の式に注記の行自身の `gap` が入っていない／§4.4 の丸の `margin-top` がルビのある行で成り立たない（§4.11 の式と結び付いていない）／§4.13 の flow が `align-items: center` 固定で段の高さがそろわない／交差軸の `margin: auto` の可否／縦書きで交差軸が既定の stretch で紙面いっぱいに伸びること。
