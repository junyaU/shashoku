## 4. hint の評価

- **効いた**（`hints_misleading` は全件ゼロ）: grid → flex + `flex: 1 1 0`（case08 を 1 往復で）、inline-block → flex の親 + `flex: none`、inline への箱プロパティ、**`background-clip: text` と `color: transparent` は一緒に外す**（無ければ見出しが消えていた）、**タグ名セレクタ**（10 件全部に出て直し方が一意。これが無ければ「書いたのに効かない規則」を黙って通していた）、`min-height` の条件つき、ベンダー接頭辞、`writing-mode` は最上位だけ
- **font-not-found**: 原因は即分かるが、埋め込みフォントだけの環境では打つ手が無い（`--font` で渡すフォントが無い）。`--strict` 運用ではこれだけで 5 件落ちる。「警告して描く」の設計どおりで、fidelity を 3 に押し下げたのは明朝の要求が満たせない事実そのもの
- **無くて困った**: `align-self`（上）、`transform`（三角・回転は不可と言ってほしい）、`table` / `tr` / `td`（上）、`image-not-found`（**渡した画像の名前を教えない**。case06 は `avatar.png` と書いて `--image avatar=` で渡していた）、`border-radius` の複数値（overflow を落としたあとの代替が無いことに触れない）

## 5. 辺ごとの border と overflow: hidden

- 区切り線 13 か所 → 1px / 2px の div で**用途を満たせた**。ただし親が `justify-content: space-between` の flex だと、div を足すと項目数が変わって配置が崩れる（case06。ラッパを 1 枚足して回避。hint はこの副作用に触れていない → hint に一言足す候補）
- 枠の一辺 = 色のアクセント帯 3 か所（case02 上 4px、case03 左 4px、case07 左 4px）→ hint どおり削除し、**用途は満たせない**（前回と同じ 3 件。「箱を flex 行にして先頭に 4px の div」の定石をガイドと hint に）
- `overflow: hidden` を落として角が崩れたのは 2 件（case03 / 08。前回と同じ）

## 6. 読み方の限界

- 書き手・直し手は opus 1 モデル。1 セッションで順に直したので学習の持ち越しはある（前回と同条件）
- 依頼は既知の 10 件。未知の依頼への一般化は未検証
- 「エラー 0 = 絵が正しい」ではない（§3）。strict の成功は「対応範囲の中で、検出対象の検査を満たした」まで（DESIGN.md §3-6）
